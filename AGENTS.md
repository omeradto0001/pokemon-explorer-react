# Project Agent Guidelines

- Work iteratively: complete only **one task at a time** from `tasks.md`, then stop. Do not begin the next task unless asked.
- Keep code simple, clean, and modular. Use React and avoid unnecessary external libraries.
- Follow core React principles: separate components by responsibility, pass data and handlers through props, and keep shared state in the nearest common ancestor.
- After completing a task, update its checkbox in `tasks.md` from `[ ]` to `[x]` and briefly explain the changes made.
- Do not start application implementation until asked to work on a task.
